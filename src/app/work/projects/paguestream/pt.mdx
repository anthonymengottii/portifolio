## Visão Geral

O **PagueStream** é uma plataforma para streamers e criadores de conteúdo receberem doações via PIX em tempo real durante transmissões ao vivo. Objetivo: conectar criadores e comunidade com uma solução segura, rápida e personalizável, sem expor dados pessoais dos doadores. Inclui processamento instantâneo de PIX, widgets de alerta e QR code customizáveis, integração com StreamElements e StreamLabs, moderação de conteúdo com IA (OpenAI), text-to-speech (Cartesia), dashboard com métricas em tempo real e fluxo de KYC. O **projeto foi discontinuado**; esteve em produção em [paguestream.com](https://paguestream.com/). O código permanece disponível como referência no [GitHub](https://github.com/anthonymengottii/paguestream_public). Licença MIT.

## Funcionalidades

**Sistema de pagamentos:** PIX em tempo real, integração com gateway (ExpaySolutions/PagueSafe), cálculo automático de taxas, histórico de transações, saques automatizados.

**Widgets:** Alerta (notificações animadas com áudio), QR Code para checkout rápido; personalização de cores e estilos; atualização em tempo real via WebSocket. Integração com StreamElements, StreamLabs e widgets standalone para OBS.

**IA:** Moderação de conteúdo com OpenAI; text-to-speech com Cartesia; correção gramatical para áudio.

**Dashboard e analytics:** Painel em tempo real de doações, métricas e insights, melhores dias/horários, gráficos interativos, relatórios financeiros.

**Outros:** Saques com validação, upload e validação de documentos (KYC), emails transacionais (Resend), sistema de feedback.

## Tecnologias Utilizadas

- **Next.js**: Framework para frontend e backend
- **TypeScript**: Type-safety em todo o projeto
- **WebSockets**: Comunicação em tempo real para notificações
- **API PIX**: Integração com sistema de pagamentos instantâneos brasileiro
- **OBS WebSocket**: Integração com OBS Studio para overlays

## Desafios e Soluções

- **Tempo real:** WebSocket para comunicação bidirecional → atualizações instantâneas em todos os clientes.
- **Moderação:** Integração com OpenAI → conteúdo inapropriado bloqueado antes de ser exibido.
- **Text-to-speech:** Cartesia → mensagens em áudio com voz natural.
- **Escalabilidade:** Monorepo com Turborepo → build e deploy otimizados.

## Resultado

Plataforma que esteve em produção em [paguestream.com](https://paguestream.com/) e foi **discontinuada**. Incluía checkout personalizado, widgets de alerta e QR code, dashboard em tempo real, métricas e integrações StreamElements e StreamLabs. Arquitetura com 3 aplicações principais, 15+ tecnologias. O código segue disponível no GitHub como referência de projeto full-stack com pagamentos em tempo real, IA e WebSocket.
