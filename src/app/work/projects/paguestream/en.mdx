## Overview

**PagueStream** is a platform for streamers and content creators to receive PIX donations in real time during live streams. Goal: connect creators with their community through a secure, fast and customizable solution without exposing donors' personal data. It includes instant PIX processing, customizable alert and QR code widgets, StreamElements and StreamLabs integration, AI content moderation (OpenAI), text-to-speech (Cartesia), real-time metrics dashboard and KYC flow. Project live at [paguestream.com](https://paguestream.com/). Reference code on [GitHub](https://github.com/anthonymengottii/paguestream_public). MIT license.

## Features

**Payments:** Real-time PIX, gateway integration (ExpaySolutions/PagueSafe), automatic fee calculation, transaction history, automated withdrawals.

**Widgets:** Alert (animated notifications with audio), QR Code for quick checkout; customizable colors and styles; real-time updates via WebSocket. Integration with StreamElements, StreamLabs and standalone OBS widgets.

**AI:** Content moderation with OpenAI; text-to-speech with Cartesia; grammatical correction for audio.

**Dashboard and analytics:** Real-time donation panel, metrics and insights, best days/times, interactive charts, financial reports.

**Other:** Withdrawal validation, document upload and validation (KYC), transactional emails (Resend), feedback system.

## Technologies Used
- **Next.js**: Framework for frontend and backend
- **TypeScript**: Type-safety throughout the entire project
- **WebSockets**: Real-time communication for notifications
- **PIX API**: Integration with the Brazilian instant payment system
- **OBS WebSocket**: Integration with OBS Studio for overlays

## Challenges and Solutions

- **Real time:** WebSocket for bidirectional communication → instant updates across all clients.
- **Moderation:** OpenAI integration → inappropriate content blocked before display.
- **Text-to-speech:** Cartesia → messages converted to natural-sounding audio.
- **Scalability:** Turborepo monorepo → optimized build and deploy.

## Outcome

Platform that was live at [paguestream.com](https://paguestream.com/) and has been **discontinued**. It included custom checkout, alert and QR code widgets, real-time dashboard, metrics and StreamElements/StreamLabs integrations. Architecture with 3 main applications, 15+ technologies. The code remains available on GitHub as a reference full-stack project with real-time payments, AI and WebSocket.
