<div align="center">
  # SDKs Oficiais da Upay
</div>

Conjunto de **SDKs oficiais** da Upay para facilitar a integração da plataforma de pagamentos em várias linguagens. O repositório é um monorepo com pacotes publicados: em vez de chamar a API REST manualmente, o desenvolvedor instala o pacote da linguagem e usa métodos tipados para criar links de pagamento, listar transações, gerenciar produtos, clientes, cupons e verificar assinaturas de webhooks. Cada SDK tem documentação própria na pasta `packages/` e exemplos em `examples/`. Código no [GitHub](https://github.com/anthonymengottii/upay-sdks). Licença MIT.

## Pacotes Disponíveis

- **JavaScript/TypeScript** — `@upay/upay-js` — ✅ Pronto para uso — `npm install @upay/upay-js`
- **Python** — `upay-python` — ✅ Pronto para uso — `pip install upay-python`
- **PHP** — `upay/upay-php` — ✅ Pronto para uso — `composer require upay/upay-php`
- **Java** — SDK Java — 🚧 Em desenvolvimento

## Funcionalidades Implementadas

Os SDKs abstraem a complexidade das chamadas HTTP e autenticação, oferecendo métodos tipados e intuitivos para:

- **Links de Pagamento**: Criação e gestão completa.
- **Transações**: Consulta e listagem com filtros.
- **Produtos e Clientes**: Gerenciamento de catálogo e base de clientes.
- **Cupons**: Validação e aplicação de descontos.
- **Webhooks**: Verificação de assinaturas de segurança para processamento de eventos.

## Início Rápido (TypeScript)

```typescript
import UpayClient from '@upay/upay-js';

const upay = new UpayClient({
  apiKey: 'sua_api_key_aqui',
  baseUrl: 'https://upay-sistema-api.onrender.com', // Opcional
});

// Criar link de pagamento
const paymentLink = await upay.paymentLinks.create({
  title: 'Produto Premium',
  amount: 10000, // R$ 100,00 em centavos
  description: 'Descrição do produto',
});
console.log(upay.paymentLinks.getCheckoutUrl(paymentLink.slug));

// Listar transações
const { data: transactions } = await upay.transactions.list({ page: 1, limit: 10 });
```

A API Key é obtida no **Dashboard Upay** em Configurações → API Keys. Documentação completa da API no link do repositório.

## Resultado

SDKs publicados e em uso por parceiros. A tipagem estática (TypeScript, type hints em Python, docblocks em PHP) reduz erros de integração; a documentação por pacote e os exemplos em `examples/` aceleram o onboarding. O monorepo inclui workflows (`.github/workflows`), CONTRIBUTING e SETUP para desenvolvimento. Suporte: suporte@upaybr.com.
