<div align="center">
  # Upay Official SDKs
</div>

Set of **official Upay SDKs** to simplify payment platform integration across multiple languages. The repo is a monorepo with published packages: instead of calling the REST API manually, the developer installs the language package and uses typed methods to create payment links, list transactions, manage products, clients, coupons and verify webhook signatures. Each SDK has its own docs under `packages/` and examples in `examples/`. Code on [GitHub](https://github.com/anthonymengottii/upay-sdks). MIT license.

## Available Packages

- **JavaScript/TypeScript** — `@upay/upay-js` — ✅ Ready — `npm install @upay/upay-js`
- **Python** — `upay-python` — ✅ Ready — `pip install upay-python`
- **PHP** — `upay/upay-php` — ✅ Ready — `composer require upay/upay-php`
- **Java** — Java SDK — 🚧 In development

## Implemented Features
The SDKs abstract the complexity of HTTP calls and authentication, offering typed and intuitive methods for:
- **Payment Links**: Full creation and management
- **Transactions**: Query and listing with filters
- **Products and Customers**: Catalog and customer base management
- **Coupons**: Validation and application of discounts
- **Webhooks**: Signature verification for secure event processing

## Quick Start (TypeScript)

```typescript
import UpayClient from '@upay/upay-js';

const upay = new UpayClient({
  apiKey: 'your_api_key_here',
  baseUrl: 'https://upay-sistema-api.onrender.com', // Optional
});

// Create payment link
const paymentLink = await upay.paymentLinks.create({
  title: 'Premium Product',
  amount: 10000, // R$ 100.00 in cents
  description: 'Product description',
});
console.log(upay.paymentLinks.getCheckoutUrl(paymentLink.slug));

// List transactions
const { data: transactions } = await upay.transactions.list({ page: 1, limit: 10 });
```

API Key is obtained in the **Upay Dashboard** under Settings → API Keys. Full API documentation linked in the repo.

## Outcome

SDKs are published and in use by partners. Static typing (TypeScript, type hints in Python, docblocks in PHP) reduces integration errors; per-package documentation and examples/ speed up onboarding. The monorepo includes workflows (.github/workflows), CONTRIBUTING and SETUP for development. Support: suporte@upaybr.com.
