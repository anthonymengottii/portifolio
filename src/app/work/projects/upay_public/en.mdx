## Overview

**Upay** is a full-stack payment gateway built from scratch. It handles the complete payment lifecycle — from PIX (instant payments) and credit cards to an affiliate marketplace, balance management, and regulatory compliance — with a security-oriented architecture and strict TypeScript throughout the project.

Developed to compete in depth and reliability with major Brazilian payment platforms (Iugu, Pagar.me, Hotmart), while maintaining the flexibility to be used as a white-label solution.

---

## Technical Highlights

### 🔐 Security & Compliance
- **Strict TypeScript mode** across frontend and backend
- **KYC Flow** with document upload, administrative review, and status webhooks
- **JWT Authentication** with bcrypt, plus API Key support for external integrations
- **Role-Based Access Control (RBAC)** with 18 granular permission flags
- **Rate limiting** by `userId` on authenticated routes
- **Idempotency keys** for transaction creation
- **HMAC-SHA256 webhook signatures** with timing-safe comparison
- **CPF/CNPJ validation** using the mod-11 algorithm
- **XSS sanitization** in transaction metadata

### 💳 Payment Processing
- **Multi-method**: PIX (instant), credit/debit card (up to 12x installments), boleto (bank slip)
- **PSP Integration**: Ameii gateway with asynchronous PIX processing and status synchronization
- **Circuit breaker** for PSP calls to isolate failures
- **Webhook delivery** with automatic retries
- **Automatic card release** — 30 days upfront or per installment
- **Payment split** via Pagar.me
- **Advanced sales tracking** — capturing UTMs (`utm_source`, `utm_medium`, `utm_campaign`) and click IDs (`fbclid`, `gclid`) using Utmify

### 🤝 Affiliate Marketing System (v2.22.0)
- **Marketplace**: merchants create affiliate programs per product; affiliates browse and request affiliation
- **Unique trackable links** — `/pay/{slug}?aff={CODE}` with configurable cookie window
- **Automatic commissions**: credited to the affiliate's wallet upon payment confirmation — types `PERCENTAGE` or `FIXED`
- **Link metrics**: click counters, conversions, and commission statuses
- **Program configuration**: description, rules, affiliate page, and sales page
- Commission processing via atomic `prisma.$transaction`

### 🏗️ Architecture & Engineering
- **Monorepo** with independent `api/` (Node.js) and `src/` (React) modules
- **Service layer**: domain services (`transactionService`, `affiliateService`, `referralService`, `webhookService`) isolated from controllers
- **Prisma ORM** with versioned migrations on PostgreSQL
- **Redis** for caching and rate limit counters
- **Cloudinary** for image storage with automatic WebP optimization
- **gzip/brotli compression** on all responses
- **Subdomain routing**: `app.[domain].com` (dashboard) vs `checkout.[domain].com` (public checkout)
- **OpenAPI 3.0 specification** maintained in code and published via Mintlify

### 🛠️ Administrative Panel
- **Kanban Board** — full CRUD operations with priority levels, assignees, and status columns
- **Granular RBAC** — custom roles with permission toggles (`approve_kyc`, `view_transactions`, `approve_withdrawals`, among others)
- **Email template management** — Handlebars templates with perfectly attached PDF receipts
- **Audit dashboard** — KYC queue, withdrawal approvals, anticipation requests, transaction management

### 🧪 Testing & CI/CD
- **Unit test suites** (Vitest) covering transactions, wallets, payment links, profiles, anticipations, transfers, and coupons
- **E2E Pipeline** using a real PostgreSQL instance
- **GitHub Actions** with separate `unit.yml` and `e2e.yml` workflows
