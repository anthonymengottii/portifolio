## Overview

**Upay** is a white-label payment platform in production, used by partners and merchants to process real transactions. Built with **Clean Architecture**, it allows companies to process PIX, card and boleto with full control over fees, customers, transactions and reports.

The stack is **TypeScript/Node.js 20+** on the backend (Express, Prisma 6, PostgreSQL, Redis), **React 18 + Vite** on the frontend (Tailwind CSS, shadcn/ui, React Query v5, Chart.js/Recharts), interactive documentation via **Swagger/OpenAPI** and production monitoring with **Sentry**. Source code available at [github.com/anthonymengottii/upay_sistema](https://github.com/anthonymengottii/upay_sistema).

## Main Features

### Payments & Checkout
- **PIX, Card and Boleto** with 8+ integrated PSPs: Pagar.me, Fyntra, Citrex, Pagflex, Axis, Ezzy, Ameii and CelCoin — automatic dynamic routing by business rules, fees and availability
- **Payment Links** with unique slug, automatic stock control and Meta Pixel per link
- **Public Checkout** with customizable theme (color, logo, texts) on a separate subdomain (`checkout.[domain].com`)
- **Checkout Builder**: configurable layout per section — personal data, address, order summary, payment method and social proof, each with up to 6 visual variants
- **Installment Payments** up to 12x with automatic release (30-day lump sum, 1 installment/month for installment plans)
- **Split Payments** via Pagar.me recipients with automatic margin calculation and remittance
- **Idempotency** across all methods — duplicate request protection with PostgreSQL advisory locks
- **Automatic Retry** with backoff on PSP failures

### Conversion Optimization
- **Order Bumps** — one-click additional offer post-payment
- **Upsells and Downsells** — dynamic recommendations based on order
- **Cart Abandonment Recovery** — automatic tracking and re-engagement
- **Coupons** — percentage or fixed discount with expiration, usage limits and rate limiting on validation
- **UTMify** — advanced sales attribution by UTM (source, medium, campaign, etc.)
- **Shopify Integration** — e-commerce product and order synchronization

### Security & Compliance
- **MFA (Google Authenticator)** — TOTP with automatic QR code, required for sensitive operations
- **Progressive KYC** — PF/PJ verification with approval levels, transaction limits per level and feature blocking until approval
- **Granular RBAC** — 15+ admin roles with specific permissions per resource
- **API Keys** with rate limiting (100 req/15 min) and complete audit logs
- **Webhooks** with signature verification, automatic retry and event history
- **Audit Trail** — all relevant actions recorded (KYC approvals, logins, configuration changes, withdrawals)

### Financial & Operations
- **Wallet & Balance** — complete credit/debit ledger in real time
- **Withdrawals and Transfers** — approval workflow with BaaS integration
- **Receivables Advance** — early settlement request for future installments
- **Custom Fees** — per method and company, with history and reports
- **Financial Reserve** — blocked balance control for transactions in processing
- **Inventory** — automatic decrement, reservation and link deactivation at zero stock

### Rewards & Community
- **Rewards System** — revenue-based tiers with header progression and benefit claiming
- **Referral Program ("Indique e Ganhe")** — unique code per user, fixed reward and recurring commission with KYC validation
- **Suggestions Board** — public feed with categories (New, Suggestion, Trending, Improvement, Bug) and community votes
- **Public Roadmap** — feature kanban (Idea → In Development → Done) with voting

### Infrastructure
- **Cloudinary CDN** — image storage and automatic optimization (products, KYC, avatars)
- **Dynamic Subdomains** — `app.[domain].com` and `checkout.[domain].com` with dynamic CORS
- **Professional Emails** — Handlebars templates, PDF receipt as attachment, dark mode prevention
- **Sentry** — production error tracking with alerts
- **Prometheus Metrics** — performance metrics for monitoring
- **Frontend Logging** — client-side error aggregation
- **Health Checks** — database and service monitoring with query optimization recommendations

All support: link creation and management, transactions, products, customers, coupon validation and webhook signature verification.

## Checkout Builder

Each payment link can have its own layout without changing code. The merchant configures variants per block in the dashboard: **personal data**, **address**, **order summary**, **payment method** and **social proof** — each with up to 6 visual options (Standard, Classic, Compact, Minimal, Tabs, Carousel, etc.). Configuration is saved per link and reflects immediately in the public checkout.

## Quality & Testing

- **1,037 tests**: 900 unit + 137 E2E
- **17 unit test suites** — services, utilities, financial calculations
- **13 E2E suites** — critical flows: authentication, KYC, withdrawals, transfers, PSP webhooks, payment links
- **CI/CD with GitHub Actions**: unit tests on every push (~30s); E2E on main/PRs with real PostgreSQL (~6min)
- **External technical audit**: 9.5/10 for a 7-month project with a small team
- **17 critical bugs fixed** in the hardening phase — race conditions, atomicity and TOCTOU vulnerabilities in financial routes

## Technologies Used

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, shadcn/ui, React Query v5, Recharts, Framer Motion
- **Backend**: Node.js 20+, TypeScript, Express 4, Prisma 6, PostgreSQL 13+, Redis 6+
- **Security**: JWT, bcrypt, otplib (MFA), Helmet, rate limiting with Redis
- **Integrations**: Pagar.me, Fyntra, Citrex, Pagflex, Axis, Ezzy, Ameii, CelCoin, Cloudinary, Twilio, Shopify, UTMify, Sentry
- **Testing**: Jest 30, ts-jest, Supertest, Vitest (frontend)
- **Documentation**: Swagger/OpenAPI

## Result

Platform in production at [app.upaybr.com](https://app.upaybr.com/) with real transactions processed daily. The Swagger documentation (`/api/docs`) and official SDKs enable fast integration. The public roadmap and suggestions board are active, with partners and users contributing votes.
