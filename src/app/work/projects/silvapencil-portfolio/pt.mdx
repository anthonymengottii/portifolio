## Visão Geral

O portfólio do **Silva Pencil** foi construído para entregar não apenas beleza, mas performance e interatividade extrema. Transformamos a apresentação de projetos de design em uma experiência viva, onde cada interação do usuário gera uma resposta visual sofisticada. O site é focado em conversão e impacto, utilizando as tecnologias mais modernas do ecossistema Web.

## Diferenciais de Design e Tecnologia

### 🔦 Interactive Grid Background
Um fundo de grade dinâmico que reage ao cursor do mouse. Utiliza `framer-motion` e variáveis CSS para criar um rastro de luz azul (ambient glow) que segue o usuário por todo o site, proporcionando profundidade e fluidez.

### 🖼️ Behance Auto-Cover Scraper
Sistema inteligente que permite adicionar apenas a URL de um projeto do Behance. O site automaticamente busca a capa em alta definição, título e autor via API interna, eliminando a necessidade de upload manual de imagens.

### 🕹️ 3D Project Tilt & Glare
Galeria de projetos interativa onde os cards possuem inclinação 3D e reflexo dinâmico (glare) baseados na posição do mouse, proporcionando uma sensação de profundidade física aos trabalhos apresentados.

### 📱 Smart Mobile Experience
No celular, onde não existe hover, o site detecta automaticamente qual card de projeto está centralizado na tela (via `useInView`) e exibe as informações dinamicamente, garantindo que o usuário mobile tenha a mesma riqueza de informações que o de desktop.

## Funcionalidades e Seções

- **Hero Cinematográfico**: Apresentação com headline de impacto e animações em camadas.
- **Galeria Inteligente**: Grid de trabalhos com integração automática ao Behance.
- **Planos Estratégicos**: Seção de precificação com hierarquia visual clara e badges de popularidade.
- **FAQ Animado**: Perguntas frequentes em accordion sofisticado.
- **Conversão**: CTAs estratégicos para contato direto via WhatsApp.

## Stack Tecnológico

- **Next.js 15.2.4**: App Router e API Routes para o motor de scraping.
- **React 19.0**: Performance otimizada com as últimas features do React.
- **Framer Motion 12**: Animações de alto nível e interações 3D complexas.
- **Tailwind CSS 4**: Estilização moderna e utilitária.
- **TypeScript 5.0**: Segurança e escalabilidade no desenvolvimento.
- **Zustand**: Gerenciamento de estado leve e rápido.

## Resultado

Um site ultra-premium que eleva o padrão de portfólios de design, unindo estética cinematográfica com engenharia de software de ponta. Totalmente responsivo e otimizado para conversão.
