## Overview

The **Silva Pencil** portfolio was built to deliver not just beauty, but extreme performance and interactivity. We transformed the presentation of design projects into a living experience, where every user interaction generates a sophisticated visual response. The site is focused on conversion and impact, using the most modern technologies in the Web ecosystem.

## Design and Technology Highlights

### 🔦 Interactive Grid Background
A dynamic grid background that reacts to the mouse cursor. It uses `framer-motion` and CSS variables to create a blue light trail (ambient glow) that follows the user throughout the site, providing depth and fluidity.

### 🖼️ Behance Auto-Cover Scraper
An intelligent system that allows adding just a Behance project URL. The site automatically fetches the high-definition cover, title, and author via an internal API, eliminating the need for manual image uploads.

### 🕹️ 3D Project Tilt & Glare
An interactive project gallery where cards have 3D tilt and dynamic reflection (glare) based on mouse position, providing a physical sense of depth to the presented works.

### 📱 Smart Mobile Experience
On mobile, where there is no hover, the site automatically detects which project card is centered on the screen (via `useInView`) and displays information dynamically, ensuring mobile users have the same richness of information as desktop users.

## Features and Sections

- **Cinematic Hero**: Presentation with impact headline and layered animations.
- **Smart Gallery**: Project grid with automatic Behance integration.
- **Strategic Plans**: Pricing section with clear visual hierarchy and popularity badges.
- **Animated FAQ**: Frequently asked questions in a sophisticated accordion.
- **Conversion**: Strategic CTAs for direct contact via WhatsApp.

## Tech Stack

- **Next.js 15.2.4**: App Router and API Routes for the scraping engine.
- **React 19.0**: Optimized performance with the latest React features.
- **Framer Motion 12**: High-level animations and complex 3D interactions.
- **Tailwind CSS 4**: Modern utility-first styling.
- **TypeScript 5.0**: Security and scalability in development.
- **Zustand**: Lightweight and fast state management.

## Outcome

An ultra-premium site that raises the bar for design portfolios, joining cinematic aesthetics with cutting-edge software engineering. Fully responsive and optimized for conversion.
