## Overview

Portfolio site built for **Silva Pencil**, graphic designer and social media specialist. **Commissioned project** (repository private). Front-end only: institutional page with a cinematic hero, animations across the experience, recent work, testimonials, social media and visual identity plans, FAQ and WhatsApp CTAs. Focus on impact and conversion. Live at [silvapencil-portifolio.vercel.app](https://silvapencil-portifolio.vercel.app).

## Cinematic hero

The hero fills the viewport with a video-like feel: bold typography, layered entrance and a narrative feel. Elements appear in sequence (staggered), with smooth transitions and a rhythm designed to capture attention before scroll. Background and copy work together for a strong, memorable first impression.

## Animations

- **Hero**: Staggered entrance for title, subtitle and CTA; smooth fade/slide transitions.
- **Scroll**: Scroll-triggered animations as sections (projects, testimonials, plans) enter the viewport.
- **Interactions**: Hover on project and testimonial cards; animated accordion in the FAQ; micro-interactions on buttons and links.
- **Parallax / depth**: Layered motion where used to add a sense of depth.

All implemented with performance in mind (CSS and/or light libraries) to keep the site smooth on mobile.

## Features and Sections

- **Hero**: Cinematic intro for Silva Pencil with impact headline and CTA to projects
- **Projects**: Grid of recent work with filters (Visual Identity, Social Media, Motion Design)
- **Testimonials**: Client testimonial cards
- **Social Media Plans**: Pricing (Essencial, Profissional, Expert) with benefits
- **Visual Identity Packages**: Levels 1, 2 and 3 with description and pricing
- **FAQ**: Frequently asked questions in animated accordion
- **Final CTA**: Contact via WhatsApp
- **Footer**: Legal info and contact

## Tech Stack

- **Next.js**: React framework for production and SEO
- **React** and **TypeScript**: UI and typing
- **Animations**: CSS (transitions/keyframes) and/or motion library (e.g. Framer Motion)
- **Styling**: CSS modules or Tailwind
- **Deploy**: Vercel

## Outcome

Responsive, conversion-focused site with a cinematic hero and animations that elevate the experience without hurting performance. Clear navigation and sections aligned to the designer’s services. Commissioned project; full front-end implementation, no backend.
